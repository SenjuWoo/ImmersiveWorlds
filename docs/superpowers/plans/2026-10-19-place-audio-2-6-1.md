# Immersive Worlds 2.6.1 "Places you can hear" — Implementation Plan

**Goal:** a place bed (water, fire, room, leaves, hum) and synthesised one-shots on top of 2.6.0's weather, driven by the same state and the same refresh.

**Architecture:** `audio.js` gains `LAYERS`, `PLACE`, `EVENTS`, `placeSpec` and merges everything into `audioSpec`. `player.js` gains five chains, two LFOs, a `spark()` voice bank and an event timer. `index.js` passes two new switches and once-per-tick cues.

**Spec:** `docs/superpowers/specs/2026-10-19-place-audio-design.md`

## Constraints
- No files, no dependencies, no prompt or schema change.
- `kit.js`, `llm.js`, `models.js`, shared kit CSS untouched.
- Weather behaviour unchanged; `weatherSpec` keeps its signature.
- Every new rule gets a node test; the browser probe re-runs.

## Tasks
- [ ] **1. `audio.js`**: `LAYERS`, `PLACE`, `EVENTS`, `placeSpec`, `eventSet`, merge into `audioSpec`, extend `specKey`.
- [ ] **2. `player.js`**: five layer chains, water/flicker LFOs, `spark()` (bird, drip, creak, footstep, door, coin, chair, page), event timer with a 700 ms floor, cues.
- [ ] **3. `index.js`**: `audioPlace`, `audioEvents` defaults; `applyAudio` passes both plus cues from `scene.arrived`/`scene.left` once per tick; reset the tick on chat change.
- [ ] **4. `settings.html`**: two checkboxes under Sound.
- [ ] **5. Tests**: layer table, event sets per slot, merge, toggles, spec identity, wiring.
- [ ] **6. Verify**: `npm test`, browser probe extended to the place layers, then docs, version 2.6.1, commit, push, CI, release.
